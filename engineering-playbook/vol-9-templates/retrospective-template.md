## Example: Sprint 18 Retrospective (Key Sections)

### Quantitative Metrics Review

| Metric | This Sprint | Previous | Target | Trend |
|--------|------------|----------|--------|-------|
| Story completion rate | 76% | 88% | >= 85% | Down |
| Carry-over rate | 24% | 9% | <= 10% | Down |
| Deployment frequency | 3 | 5 | >= 4 | Down |
| PR merge time median | 31 hours | 19 hours | <= 24 hours | Down |
| Test pass rate | 99.1% | 98.8% | >= 98% | Stable |
| Bug rate | 0.38 | 0.22 | <= 0.3 | Down |

**Metric highlights:** Carry-over rate (24%) and PR merge time (31h median) both broke through their targets this sprint. Both are worth discussion in Start/Stop.

### AI Collaboration Review (Excerpt)

**What AI-Generated Code Needed the Most Rework?**

| Story | AI Task | Rework | Root Cause |
|-------|---------|--------|-----------|
| MW-438 | Generated the `TampXmlExporter` class including field mappings | High | The prompt did not include the TAMP field mapping document from vault/. AI invented plausible-looking but incorrect IRI-to-HMS-element mappings. Ravi spent ~3 hours correcting the XML output against the spec. |

**Prevention suggestion:** Add to CLAUDE.md: "When generating TAMP-related code, always read `vault/calculations/TampBridgeMapping.md` and `vault/calculations/TampPavementMapping.md` before writing any field mapping logic."

**What AI Workflows Saved the Most Time?**

| Workflow | Time Saved | Notes |
|----------|-----------|-------|
| Generating FluentValidation validators from DTO schemas | ~4 hours | Validators were accurate on first pass; only minor tweaks for custom error messages |
| Writing QuestPDF template boilerplate for bridge PDF | ~2 hours | Layout code was correct; custom styling required manual work |

### Committed Actions for Sprint 19

1. **Always attach relevant vault/ spec documents to AI prompts for domain-specific code generation** — Owner: Ravi, Due: Sprint 19 day 1 (update CLAUDE.md)
2. **Add PR reviewers at story assignment time, not at PR creation, to reduce review queue time** — Owner: Priya, Due: Sprint 19 planning
3. **Break down any story estimated >= 8 points before sprint commitment** — Owner: Meera + Priya, Due: Sprint 19 grooming
