# Masterworks Plan — Release Notes

**Release 2026.07 — July 10, 2026**
Audience: capital planning teams at state and local government agencies

## New in this release

- **Grant Milestone Tracking** (Funding) — Track state and federal grant milestones against the program schedule, with drawdown deadlines surfaced on the program dashboard so agencies never miss an obligation date. Released 2026-07-10.
- **Multi-Year Program Rollup** (Capital Planning) — Roll district-level capital plans into one multi-year program view with fiscal-year phasing and carry-forward handling. Released 2026-07-10.
- **Public Meeting Exports** (Reporting) — Produce board-ready program summaries formatted for public meetings, including project lists, funding sources, and delivery status. Released 2026-07-10.

## Changed

- **Scenario Comparison** (Capital Planning) — The constraint editor now supports bond-issue timing as a constraint, so planners can compare funding scenarios against realistic debt schedules.
- **Federal Fund Tracking** (Funding) — Drawdown visibility now includes FHWA apportionment categories. FHWA reporting fields map directly to agency submittal formats.

## Deprecated

- **Legacy CSV Plan Import** (Migration) — Retired in this release. Agencies migrating historical plans should use the guided import workspace, which validates project data across the full program life cycle before it lands in the plan of record.
