PMM Agent — System Architecture

Operation Blackbriar · React SPA + Express API + Claude, grounded in the GTM War Room knowledge base

Ask → Answer Flow

  • • User signs in via Supabase Auth; every /api call carries the JWT and resolves to a role (admin / sales / marketing / elt)
  • • askRouter classifies each ask: plain question vs. artifact request — routing failures always degrade to a direct answer, never a block
  • • claude.ts sends a byte-stable system prefix (voice rules + guardrails + Brand DNA) so the Anthropic prompt cache holds across requests
  • • Every answer ends with a Sources: line tracing to war-room files; queries are logged to Supabase

Asset Pipeline & Guardrails

  • • Studio / quick-generate fill template slots via the agents registry (6 task agents + 14 PMM sub-agents)
  • • Voice Guard runs the deterministic forbidden-words check — the same list as the Claude Code PostToolUse hook
  • • Everything lands as a draft; only PMM admin approval moves an asset to final
  • • Finalized artifacts export as styled HTML to the local Output folder

Knowledge & Ingestion

  • • GTM-War-Room/ markdown is content truth — shared byte-for-byte with the Claude Code workspace
  • • SharePoint polling, the chokidar Input-folder watcher, and the uploads console all funnel through ingestDocument()
  • • Documents are extracted, sha-256 deduped, and split into heading-aware ~1.4k-char chunks for ranked retrieval
  • • Supabase is optional: without credentials the app runs file-only
