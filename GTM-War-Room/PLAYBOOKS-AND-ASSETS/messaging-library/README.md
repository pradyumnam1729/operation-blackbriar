# messaging-library/

Value propositions and message houses, one file per product × audience. Every entry follows the schema in Master Instructions §7.4: use case + context, the problem, what solves it, how it delivers value, the benefit, the cost of not solving it. Messaging is the bridge between positioning and copy — nothing in here is channel copy, and no copy is written anywhere without a messaging entry behind it. Seed source to import first: the Messaging House (Part B) of `reference output/Masterworks AI Messaging and Positioning.pdf`. Empty at seeding, 2026-08-06.
